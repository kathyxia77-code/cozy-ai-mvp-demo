# 设计输入

## 目录说明

- `figma-exports/`：当前 Cozy AI PRD 对应的 Figma 页面截图，是页面结构和交互状态的视觉输入。
- `assets/`：Cozie IP 等产品素材。

## 使用顺序

1. 先根据 `01-product/requirements/MVP DEMO.txt` 确认业务状态；
2. 再使用 Figma 截图确认布局、信息层级和交互位置；
3. 所有视觉数值回到 `03-design-system/` 的当前 token，不从截图取色或猜测像素值；
4. 素材进入前端工程前需复制到工程内的业务资源目录，并保留来源说明。

## 当前限制

- 截图不是可检查的 Figma 节点，无法直接读取 Auto Layout、变量绑定和组件实例；
- 截图与 PRD 冲突时先按 PRD 的合规和状态规则执行，并记录待确认项；
- 隐私协议默认未选中，即使截图展示选中态也不作为初始状态。
